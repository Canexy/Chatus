# Descripción y Estado del Proyecto: Chat en Tiempo Real (React + Supabase + Node.js/Socket.IO)

## Resumen del Proyecto
Este proyecto es una aplicación de chat en tiempo real que utiliza React para el frontend, Supabase como backend de autenticación y base de datos, y Node.js/Socket.IO para la comunicación en tiempo real. Incluye funcionalidades de administración, tema oscuro, y control de seguridad avanzado.

---

## Funcionalidades Implementadas
- **Autenticación**: Login y recuperación de contraseña por usuario o email.
- **Chat en tiempo real**: Comunicación instantánea entre usuarios usando Socket.IO.
- **Reconexión automática**: El chat es tolerante a desconexiones y cambios de pestaña.
- **Gestión de perfiles**: Creación y edición de perfil, cambio de nombre de usuario, campo email en perfiles.
- **Administración**: Menú solo visible para admin (`is_admin` en `profiles`), con funciones de borrar todos los mensajes y resetear IDs (solo admin, seguro vía RPC y RLS).
- **Tema oscuro**: Aplicado globalmente en el frontend.
- **Seguridad**: Funciones críticas protegidas por RLS y validaciones en frontend/backend.
- **Exposición temporal de `supabase`**: Para pruebas, luego eliminado.
- **Limpieza de código**: Eliminada lógica antigua de recuperación de contraseña y código innecesario.
- **Documentación**: Instrucciones de despliegue y buenas prácticas.
